# 更新日志

面向使用者的累积更新记录。每条对应一个已打包的版本，对应的安装包与冻结的发布说明在 `releases/<版本号>/`。

发布号规则：`主版本.次版本.修订号`。新增功能走次版本，修 bug / 调样式走修订号，数据结构或行为不兼容才动主版本。

## 1.2.0 · 2026-11-17

**剧透标签并回原标签流，另加六项功能**

- 剧透标签不再单独成块：按类别就地混在同类标签里，默认隐藏，右上角「显示剧透（N）」就地展开 / 收起，标题计数同步变成含剧透的总数。
- **人物卡出图**：右键「保存人物卡图片…」或详情「保存成图片」，在渲染进程 canvas 上画一张竖版人物卡（渐变底、立绘 / 头像、名字译名、定位 CV、两列资料、**按类别分组的全部特征标签**、简介、底部作品名与日期）后弹保存对话框；
  - 特征标签按类别分行、自动折行，剧透标签是否入图跟随详情里「显示剧透」按钮的状态（打开时标题追加「· 含剧透」，剧透药丸用强调色描边）；
  - 画布高度两趟布局自适应（先量后画，最短 880px），不再固定 1260 导致简介被压或下半张空白；
  - 字体与亮暗跟随主题。
- **声优聚合**：卡片与详情里的 CV 可点击，点一下即跨所有已缓存作品搜索该声优配过的角色。
- **右键换图**：右键「换成本地图片…」选本地图，复制进缓存目录（`custom__<sha1 前 16 位>`）并写进个人修正层，重新刮削不丢；随备份与导出一起走。
- **登场作品列表**：详情弹窗懒加载 `/v2/catalog/characters/{id}/appearances`，列出登场作品与定位（主角 / 配角 / 登场），标题按 `zh-Hans → zh-Hant → ja → en` 本地化，带外链的行可点。
- **快捷键**：全部落在人物详情弹窗里 —— `←` `→`（或 `↑` `↓`）切上一个 / 下一个角色、`E` 编辑、`S` 出图、`T` 展开 / 收起剧透、`Esc` 关闭；列表页只留 `/` 聚焦搜索与 `Esc` 关菜单（不做方向键选卡，鼠标点卡片更快）。
- **缓存统计**：设置行新增「缓存统计」，显示作品数 / 人物数 / 图片张数与体积 / 缓存目录 / 最早最近缓存时间 / 有效期，可一键清理过期条目（不动图片）。
- 新增 6 个 IPC 频道（`stats` / `prune-cache` / `appearances` / `pick-image` / `set-image` / `save-image`），共 13 个。
- 新增离线探针 `scripts/probe-extras.js`（25 项断言，含弹窗内 ←→ 换人与快捷键）；`probe-spoiler.js` 改成断言「就地折叠」；`smoke.js` 增补缓存统计 / 登场作品 / 清理过期三组断言。
- **修 IPC 实参形状**：Vnite 的 `api.ipc.handle` 直通 `ipcMain.handle`，handler 收到的是 `(event, payload)`；之前按 `(payload)` 写，导致「保存人物卡」报「不是有效的图片数据」、放大图不刷新、登场作品拿不到 id。现在统一用 `ipcPayload()` 解包，event / payload 两种形状都认。新增 `scripts/probe-invoke.js` 锁死这个约定。

## 1.1.0 · 2026-11-17

**标签取全量，剧透默认收起**

- 人物详情请求固定带 `spoiler=major`，把 none / minor / major 三档标签一次刮全，逐条记录档位。
- 卡片墙的小标签仍然只要「非性 + 无剧透」，翻列表不会被剧透。
- 详情弹窗「特征」默认只列无剧透标签，右上角「显示剧透（N）」展开其余部分（虚线下划线区分），可再收起 —— 与 Kungal 网页行为一致。
- 同一条标签同时以 none 与 major 出现时去重取 none；`is_lie` 的假标签照旧丢弃。
- 缓存 `schemaVersion` 1 → 2，旧缓存（只有无剧透标签）判为过期，首次打开自动重刮一次，不用手动清缓存。

**原名也参与作品匹配**

- `metadata.name`（译名）与 `metadata.originalName`（原名）一起进候选，顺序「译名 → 原名」，逐个搜索后按标题相似度取最优。
- `|`、`｜`、`/` 连接的拼接标题先拆开分别试。
- 修复译名未被 KunGalgame 收录时误报「未收录作品」的问题。

**顺带**

- API Key 失效（401）不再挡住刮削：自动降级为匿名访问并提示一次；配置改动会在下次刮削前重新读取，不必重启 Vnite。
- 新增三个离线探针：`probe-traits.js`（标签档位与原名匹配）、`probe-spoiler.js`（剧透折叠的 DOM 行为）、`probe-auth.js`（401 降级与配置热重读）。
- 回归探针适配 `schemaVersion` 2 与动态版本号。

## 1.0.0 · 2026-11-17

首发。

- 在 Vnite 的「游戏详情」里注入原生「人物」标签页，从 KunGalgame / NextMoe 公共 API 刮角色名单、头像与立绘、资料与简介。
- 卡片墙、详情弹窗（竖图 + 头像、滚轮缩放看原图）、按类别分组的特质、别名、来源外链（VNDB / ErogameScape / Bangumi / Getchu）。
- 点标签即跨作品搜索；右键编辑 / 删除；个人修正层（改动只存本地，重刮不覆盖）。
- 新建游戏自动刮削，缓存默认 30 天，本地限流保护。
- 数据搬家：导出 / 导入（数据 + 个人修正 + 图片），图片存进数据库目录，随官方「备份数据库」一起走。
- 14 项可配置项；界面滚动条统一隐藏，视觉与 Vnite 原生一致。
