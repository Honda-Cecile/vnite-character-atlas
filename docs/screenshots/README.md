# 截图清单

README 里每一节都留了预览位置，把图片按下面的文件名放进本目录即可（PNG，建议 1600px 宽以内、单张 < 500KB，免得仓库太重）。

| 文件名 | 用在哪 | 拍什么 | 建议 |
| --- | --- | --- | --- |
| `01-tab.png` | 功能 · 原生标签页 | 标签栏特写：概览 / 人物 / 记录 / 存档 / 回忆 五标签**同排**，下划线在当前标签上 | 横向裁切，能看清五个标签就够 |
| `02-cards.png` | 功能 · 人物卡片墙 | 卡片墙整体（8–12 张卡），包含头像、名字、CV、特质标签 | 建议悬停一张卡片，让 hover 效果出现 |
| `03-detail.png` | 功能 · 详情弹窗 | 人物详情弹窗：左侧立绘 + 头像，右侧资料 / 特质 / 简介 / 外链 | 选一个有完整数据、简介带「来源 + 机翻标记」的角色 |
| `04-search.png` | 功能 · 跨作品搜索 | 点某个特质（如「双马尾」）后的跨作品结果，标题显示搜索词与命中数 | 库里最好有 2 部以上已刮削作品，才有「跨作品」的感觉 |
| `05-context-menu.png` | 功能 · 右键菜单 | 卡片右键菜单展开，「编辑这个人的资料…」/「从本作人物栏删除」两项都要完整可见 | 别让菜单贴边被裁 |
| `06-editor.png` | 功能 · 编辑弹窗 | 编辑人物弹窗全貌，13 个字段都露出来 | 可以预填几个值，别空白交付 |
| `07-migrate.png` | 功能 · 数据搬家 | 设置页最下面「人物数据」一行：导出 / 导入 / 清空全部人物 / 打开缓存目录 | 顺带把上一行「导出时带上图片」也拍进画面 |
