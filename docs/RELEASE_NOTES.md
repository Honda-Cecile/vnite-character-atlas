1.2.0 · 剧透并进标签流 + 六项新功能

## 这次更新了什么

七件事：一件是样式调整（剧透标签不再单独一块），六件是从实际使用里攒下来的功能。

### 1. 剧透标签并回原来的标签流

上一版把剧透标签做成了「单独一块折叠区」，看着像多长了一个抽屉。现在它们按原来的类别（角色身份 / 性格 / 关系 …）就地混在同类标签里：

- 默认仍然只显示无剧透的那几条，列表页看到的就是一片正常标签
- 右上角「显示剧透（N）」点一下，剧透标签就在原位出现（虚线下划线区分），标题计数从「特征（3）」变成「特征（5）」
- 再点收起，回到干净状态

### 2. 人物卡出图

右键卡片 →「保存人物卡图片…」，或打开详情点「保存成图片」（详情里也能按 `S`）。插件在渲染进程的 canvas 上画一张竖版人物卡：渐变底、立绘或头像、名字与译名、定位与 CV、两列资料、**按类别分组的全部特征标签**、简介、底部作品名与日期，然后弹系统的保存对话框。

- 特征标签按类别分行、一行放不下自动折行；剧透标签是否入图，看你在详情里点没点过「显示剧透」——没点就只画无剧透的，标题写 `特征（N）`；点开了连剧透一起画，标题写 `特征（N）· 含剧透`，剧透药丸用强调色描边。
- 画布高度是「先量内容、再定尺寸」（最短 880px），资料多、简介长会自动变高，不会把简介压到标签上，也不会留半张空白。
- 字色与亮暗跟着当前主题走，不受窗口大小影响。

### 3. 声优聚合

卡片和详情里的 CV 现在可以点。点一下 = 在所有已缓存作品里搜这个名字，这位声优配过的角色按作品分列出来。

### 4. 右键换图

右键 →「换成本地图片…」，选一张本地图片：插件把它复制进缓存目录（`custom__<sha1 前 16 位>.<扩展名>`），把路径记进个人修正层 —— 重新刮削、TTL 刷新都不会把它冲掉。图片跟着官方「备份数据库」和插件自身的导出一块走。

### 5. 登场作品列表

详情弹窗新增「登场作品」：查 `/v2/catalog/characters/{id}/appearances`，列出这个角色出现过的所有作品与定位（主角 / 配角 / 登场）。作品名优先取中文字段（`zh-Hans → zh-Hant → ja → en` 依次回退，再取 `|` 前的一段），带外链的那几条点一下直接打开原站页面。

### 6. 快捷键（都在人物详情里）

打开一个人之后，这一屏全能键盘操作：

- `←` `→`（或 `↑` `↓`）切到上一个 / 下一个角色，弹窗就地换内容 —— 顺着名单往下看不用退出去再点
- `E` 编辑这个人，`S` 保存人物卡，`T` 显示 / 收起剧透，`Esc` 关弹窗

列表页只保留 `/` 聚焦搜索框。卡片不做方向键选卡：一屏就那么几张，鼠标点比按方向键快。

### 7. 缓存统计

设置页「人物数据」那一行新增「缓存统计」：已缓存多少部作品、多少个人物、图片多少张多少 MB、缓存目录在哪、最早与最近一次缓存时间、当前有效期。旁边能直接「清理过期缓存」——只删超过有效期的条目，图片和你换的图都不动。

### 顺带修掉的一个真 bug

Vnite 注入给插件的 `api.ipc` 是它自己的 IPCManager（`ipcMain.handle` 直通），所以 handler 收到的第一个参数是 `event`、payload 在第二个。上一版按「只有一个 payload」写，实机上表现为：

- 点「保存人物卡」→ `出图失败：不是有效的图片数据`
- 点开大图 → 一直停在缩略图
- 登场作品 → 拿不到角色 id，区块空着

现在统一走 `ipcPayload()` 解包，两种调用形状都认；并新增离线探针 `scripts/probe-invoke.js`（13 项断言）把这个约定钉死。

## 升级方式

1. 下载 `character-atlas-1.2.0.vnpkg`
2. Vnite → 插件 → 卸载（或禁用）旧的 Character Atlas
3. 安装新包 → **重启 Vnite**

旧缓存不用手动清：数据结构没变（`schemaVersion` 仍是 2），打开就用。

## 关于版本号

「剧透并回标签流」本该单独出一个 1.1.x，但 1.1.0 已经在插件市场发布过、附件是旧的；同版本号换内容会让已安装的人看到「版本一样、功能不同」。所以这一版把两件事合并成 1.2.0 —— 想要单独的 1.1.1 随时可以拆。

## 1.1.0 内容（存档）

标签取全量（`spoiler=major`，三档全抓、默认只显示无剧透）、原名参与作品匹配（`metadata.name` + `metadata.originalName`，按标题相似度取最优）、API Key 失效自动降级匿名并支持配置热重读、缓存 `schemaVersion` 2。

## 1.0.0 首发内容（存档）

原生「人物」标签页、卡片墙、详情弹窗、跨作品搜索、右键编辑 / 删除、个人修正层、自动刮削、导出导入（含图片）、图片跟随官方备份、本地限流、VNDB 兜底、401 自动降级匿名。
