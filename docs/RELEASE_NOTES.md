1.1.0 · 全量标签与原名匹配

## 这次更新了什么

两件从实际使用里冒出来的事：标签只刮到一半、译名搜不到就报「未收录」。

### 1. 标签取全量，剧透默认收起

KunGalgame 的角色标签分三档剧透等级：`none` / `minor` / `major`。以前插件没带 `spoiler` 参数，服务端只回默认的那一档（`none`），所以「重度剧透」的标签一直缺着 —— 明明 Kungal 网页上能看到。

- 人物详情请求固定带 `spoiler=major`，三档一起抓
- 每条标签都记着自己的剧透档位（`traits[].spoiler`）
- 卡片墙的小标签仍然是「非性 + 无剧透」，刷列表不会被剧透
- 详情弹窗「特征」区默认只列无剧透的；右上角「显示剧透（N）」点开展开 `minor` / `major` 那部分（虚线下划线区分），再点收起
- 同一条标签若同时以 `none` 和 `major` 出现，去重后只留 `none`；`is_lie` 的假标签照旧丢弃

缓存的 `schemaVersion` 从 1 升到 2：旧缓存只有无剧透标签，会被判为过期，第一次打开自动重刮一次。

### 2. 原名也参与作品匹配

Vnite 里的游戏名常是中文译名，KunGalgame 的搜索面却只认原语言名与罗马字（`q=古河渚` 0 命中，`q=Furukawa` 才命中）。以前只拿 `metadata.name` 去搜，译名没被收录就直接报「未收录作品」，其实原名一搜就有。

- `metadata.name`（译名）+ `metadata.originalName`（原名）一起进候选，顺序「译名 → 原名」
- `|`、`｜`、`/` 连接的拼接标题先拆开分别试
- 每个候选都用标题相似度打分，宁可不匹配也不错配

### 3. 顺带

- 新增 `scripts/probe-traits.js`（离线）：验证请求带 `spoiler=major`、标签带档位、`is_lie` 被丢、重复去重取最低档、原名能命中
- 新增 `scripts/probe-spoiler.js`（离线，headless Chrome）：验证卡片不含剧透标签、弹窗默认折叠、按钮文案与展开/收起行为
- 设置项数量不变（14 项），插件 id / 数据结构向后兼容

## 升级方式

1. 下载 `character-atlas-1.1.0.vnpkg`
2. Vnite → 插件 → 卸载（或禁用）旧的 Character Atlas
3. 安装新包 → **重启 Vnite**

旧的缓存数据不用清：插件会按 `schemaVersion` 自动重刮一次带剧透分级的标签。
