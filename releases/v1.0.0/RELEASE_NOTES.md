首个公开发布版 · 1.0.0

## 这是什么

给 Vnite 的游戏详情页注入一个原生样式的「人物」标签页，把该作品的角色做成卡片墙。数据来自 KunGalgame / NextMoe 的公开 API（NextMoe Public API v2），KunGalgame 未收录的作品用 VNDB 兜底，头像与立绘下载到本地。

## 为什么做它

Vnite 自带的元数据刮削只到「作品」这一层：封面、简介、开发商、评分、发售日。点进一部 galgame，看不到里面有哪些角色、长什么样、声优是谁、性格标签是什么。

这些信息在 VNDB、KunGalgame 上都能查，但要开浏览器一个个找。把整个库搬去别的管理器确实能看角色表，可那样就得放弃 Vnite 的详情页、标签栏、玻璃拟态和字体设置 —— 为了「看一眼人物」换掉整个环境不值得。

所以这个插件只做一件事：把「人物」这一层补进 Vnite 自己的详情页，长得和原生标签页一模一样。

## 主要功能

- **原生标签页**：标签栏变成「概览 / 人物 / 记录 / 存档 / 回忆」，五个标签单排不换行，样式与下划线动效和原生一致，字体跟随 Vnite 的字号 / 字重设置；React 重渲染冲掉节点会自动重插
- **卡片墙**：头像、名字、原名、别名、定位（主角 / 其他）、CV、性别 / 生日 / 身高 / 体重 / 血型 / 三围、简介摘要、特质标签（按毛发 / 眼睛 / 身体 / 服装 / 性格 / 角色…分组）、`KunGalgame #<workId>` 来源徽章
- **详情弹窗**：全身立绘 + 头像（可点开看原图、滚轮缩放）、完整资料、全部别名、简介全文（标注来源与是否为机器翻译）、特质按类别分组、来源外链（VNDB / ErogameScape / Bangumi / Getchu）；弹窗隐藏了 Windows 那根灰色滚动条（滚轮照常滚），视觉上更像原生界面
- **点特质 / 声优 → 跨所有已缓存作品搜索**；切换作品自动清空搜索状态
- **右键编辑 / 删除**：13 个字段可改（名字、原名、译名、定位、CV、性别、生日、身高、体重、血型、三围、别名、简介）。改动写入个人修正层，重新刮削或缓存过期刷新都不会覆盖；删除的角色被刮回来也会被过滤
- **新增游戏自动刮削**：游戏加进库时后台抓一次（默认开），老游戏只读缓存，不点不请求，没有定时巡检
- **数据搬家**：设置页「人物数据」一行 → 导出 / 导入 / 清空 / 打开缓存目录。导出是可读 JSON，**含刮削数据、个人修正与已缓存的头像立绘（base64）**，换机器导入一次即离线可用
- **图片跟着官方备份走**：头像缓存落在 Vnite 数据目录的 `app/database/character-atlas/images`（便携版在 `<Vnite 根>/app/database`，安装版在 `%APPDATA%/vnite/app/database`，插件启动时按 Vnite 自己的便携判定选路并写进 `%TEMP%\character-atlas\debug.log`），Vnite 的「备份数据库」（整个 `app/database` 打 zip）会把它一起带走，恢复备份后不用重新下载
- **本地图片缓存**、**VNDB 兜底**、**同名重复条目合并**、**本地限流自保**（默认 45 次/分 + 429 退避）

## 安装

1. 下载下面的 `character-atlas-1.0.0.vnpkg`
2. Vnite → 插件 → 安装插件 → 选择该文件
3. 启用后重启 Vnite

也可以在 Vnite 的「插件 → 浏览」里搜 `character atlas` 直接安装。

要求：Vnite 4.x（开发与验证于 4.15.0），能访问 `api.nextmoe.dev` 与 `api.vndb.org`。

## 已知限制

- 设置页最下面「人物数据」那四个按钮是插件**启用后注入**的 DOM：插件停用时不显示（Vnite 停用插件后不加载插件代码，配置体系里也没有按钮类型控件）。启用并重开设置对话框即会出现。这一行的外观是**克隆同容器里的一条原生设置行**再换掉文字与右侧控件，所以主题/玻璃拟态/字号变化时它跟着原生行一起变
- 标签页注入依赖 Vnite 详情页的 `[role="tablist"]` 结构，Vnite 大改版可能插不上；此时手动刮削与导出导入仍可用
- 非 Windows 平台未测试

## 备份与迁移

- **推荐**：设置页 →「导出人物数据」→ 新机器「导入人物数据」。一个 JSON，含数据 + 个人修正 + 已缓存图片，导入后离线可用。
- **用 Vnite 的备份**：`vnite-database-YYYYMMDD.zip` 里已经有插件数据（`plugin/`）和头像（`character-atlas/images/`），但 Vnite 自带的「导入数据包 / 恢复数据库」目前有 bug（选中备份包不生效或直接报错）。绕过方式：关掉 Vnite → 直接把 zip 里的 `config/ config-local/ game/ game-collection/ game-local/ plugin/ theme.v4.css` 解压覆盖到 `<Vnite>/app/database/` → 重启。详见 README「备份与迁移」。

## 数据来源与许可

人物数据来自 KunMoe 的 NextMoe Public API v2（多源聚合：VNDB / ErogameScape / Bangumi / Getchu；特质为 KunGalgame wiki 自有分类），兜底使用 VNDB Kana API。本项目以 GPL-3.0-only 发布。
